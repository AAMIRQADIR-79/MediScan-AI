# 🩺 MediScan AI

An AI-powered healthcare assistant that predicts diseases based on symptoms using machine learning.

---

## 🚀 Features

- 🤖 Random Forest ML model (200 trees)
- 🧾 Symptom-based disease prediction
- 📊 Confidence score & severity level
- 🔬 Differential diagnosis (Top 3 predictions)
- 📈 Interactive dashboard (Plotly)
- 🌍 Multilingual support (English/Hindi)
- 📋 Patient profile (age, gender, duration)
- 💾 History tracking
- 📄 Downloadable report

---

## 🧠 How It Works

User Input → Feature Encoding → ML Model → Prediction → Insights + Dashboard

---

## 🛠 Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas / NumPy
- Plotly
